# Proyecto-Inf497-2026-1-Manzano-Silva
Repositorio del proyecto de Manuel Silva y José Manzano para INF497. Consiste en analizar el aislamiento de los campamentos de Viña del Mar a servicios esenciales

------------------
Pipeline de Procesamiento y Análisis Espacial (proyecto.ipynb)
Este módulo contiene el flujo de trabajo automatizado en Python para la extracción, limpieza, geoprocesamiento y análisis estadístico espacial de los campamentos de la comuna de Viña del Mar.

Requisitos e Instalación
El script está desarrollado en Python 3.10+. Para ejecutar el notebook de forma local se necesita instalar las siguientes librerías geoespaciales y estadísticas:

pip install pandas geopandas osmnx libpysal esda beautifulsoup4 shapely fiona matplotlib seaborn
